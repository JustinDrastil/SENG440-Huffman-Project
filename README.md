# SENG440-Huffman-Project
Seng 440 Huffman encoding &amp; decoding project

The CreateTestbench.c will create the .txt file to be used when you run the Encode.c file.

The Encode.c file will create an encoded.txt file to be used when running the decode functionality.

The Decode.c file is our original implementation and the DecodeOpt2.c file is our optimized code.
